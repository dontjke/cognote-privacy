## 1\. Общие положения

Настоящая Политика конфиденциальности описывает, каким образом приложение **Cognote** («Приложение») обрабатывает данные пользователей. Используя Приложение, вы соглашаетесь с условиями данной Политики.

\---

## 2\. Какие данные собирает приложение

Приложение Cognote является **локальным приложением для создания заметок**. Все данные хранятся исключительно на устройстве пользователя.

**Приложение НЕ собирает и НЕ передаёт на серверы:**

* персональные данные пользователя
* содержимое заметок
* контакты, историю звонков или сообщений
* данные о местоположении
* идентификаторы устройства

\---

## 3\. Разрешения приложения

Приложение запрашивает следующие разрешения:

|Разрешение|Назначение|
|-|-|
|Запись аудио (RECORD\_AUDIO)|Запись голосовых заметок пользователя. Аудиозаписи хранятся локально на устройстве и не передаются третьим лицам.|
|Чтение/запись хранилища|Сохранение и импорт/экспорт заметок и вложений на устройстве пользователя.|

Все разрешения используются исключительно для обеспечения функциональности Приложения и только при явном взаимодействии пользователя.

\---

## 4\. Хранение данных

* Все заметки, настройки и файлы хранятся **локально на устройстве пользователя**.
* Приложение не использует облачные серверы для хранения пользовательских данных.
* Данные могут быть удалены пользователем в любой момент через настройки приложения или при удалении приложения с устройства.

\---

## 5\. Передача данных третьим лицам

Разработчик **не передаёт, не продаёт и не раскрывает** персональные данные пользователей третьим лицам. Приложение не содержит рекламных SDK, аналитических трекеров или сторонних сервисов сбора данных.

\---

## 6\. Безопасность данных

Для защиты данных на устройстве Приложение поддерживает:

* Шифрование заметок (при включении соответствующей функции)
* Биометрическую аутентификацию (отпечаток пальца / Face ID) для доступа к приложению

\---

## 7\. Дети

Приложение не предназначено для детей до 3 лет. Приложение не собирает данные о детях намеренно.

\---

## 8\. Изменения в политике конфиденциальности

Разработчик оставляет за собой право вносить изменения в настоящую Политику. При существенных изменениях пользователи будут уведомлены через обновление приложения или уведомление внутри Приложения. Продолжение использования Приложения после изменений означает согласие с обновлённой Политикой.
